# Arduino Example Path Moved

First-party Arduino sketches now live directly under `examples/arduino/`, next
to the repository-pinned `libraries/` directory. Update scripts and links from
`examples/arduino/examples/<sketch>` to `examples/arduino/<sketch>`.

Arduino 第一方示例现已直接放在 `examples/arduino/` 下，与仓库自带的
`libraries/` 目录同级。请将旧路径 `examples/arduino/examples/<sketch>`
更新为 `examples/arduino/<sketch>`。
