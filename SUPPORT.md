# Support

For setup and product usage, start with the [product documentation](https://docs.waveshare.com/ESP32-S3-Touch-LCD-4.3C) and the README inside the selected example.

For reproducible repository defects, open a GitHub issue and include:

- board name and hardware revision, if known;
- example path and framework version;
- complete build, flash, and serial logs;
- reproduction steps, expected behavior, and actual behavior;
- whether the image came from source CI or `firmware/`;
- any changes to pins, BSP components, board options, or SD-card resources.

For order, warranty, or product support, contact Waveshare through the channel listed on the product page and include the order number. Do not report security vulnerabilities in a public issue; follow [SECURITY.md](SECURITY.md).
