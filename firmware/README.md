# Factory Firmware

`ESP32-S3-Touch-LCD-4.3C-Test.bin` is a complete factory test and recovery image for the ESP32-S3-Touch-LCD-4.3C N16R8 variant. Flash it at offset `0x0`. Verify its SHA-256 digest against `config/factory-firmware.json` before distribution or recovery use.

`sdcard/` contains the image and music resources consumed by the factory demonstration. Copy that directory content to a FAT-formatted microSD card without renaming its subdirectories.

This factory image is separate from source-built example packages generated by CI. Source and build instructions for the factory image are not included in this repository yet and may be added later. See `docs/firmware.md` for the complete boundary and source-build flashing flow.
