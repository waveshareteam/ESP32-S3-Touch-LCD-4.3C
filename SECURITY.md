# Security Policy

Do not disclose a suspected vulnerability in a public issue.

Report security concerns privately through the contact channel listed on the [Waveshare support page](https://www.waveshare.com/contact_us.html). Include the affected repository revision, example or firmware path, impact, reproduction details, and any proposed mitigation. Avoid including credentials, private network information, or other sensitive data.

Security updates are evaluated for the currently maintained source examples. Factory recovery images are versioned separately from source-built CI artifacts; identify which firmware class and digest you tested.
